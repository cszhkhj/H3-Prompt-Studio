# H3-Prompt-Studio (H3 提示词工作台)

专为 MiniMax H3 视频模型设计的本地提示词工程工作台。纯前端、零依赖、离线可用。

## 🌟 核心特性
- **一句话生成 / 多段提示词双模式**：兼顾快速测试与工业级长视频制作。
- **工业级一致性锚定**：通过主体锚定句式、状态锚定卡与接戏锚定卡，极大降低长视频跨段换人、场景漂移的问题。
- **精细化镜头规划**：表格化控制镜头时间点、运镜、景别与转场，支持自动切分。
- **台词与口型硬约束**：强制逐字复用台词，绑定到具体镜头，确保声画同步。
- **动态编译 System Prompt**：根据用户表单动态拼接极高精度的 H3 六段式提示词指令。

## 🚀 如何使用
1. 下载仓库中的 `H3提示词工作台.html` 文件。
2. 双击用 Chrome / Edge 等现代浏览器打开即可，**无需安装任何环境**。
3. 在顶部的「本地服务地址」填入你的本地 llama-server 地址（如 `http://127.0.0.1:8080/v1`）。
4. 点击「测试连接」，成功后即可开始生成提示词。

## 📝 注意事项
- 该工具依赖本地部署的 llama-server，模型预设为 `QweN3.6_35B`（可在代码中自行修改）。
- 所有生成逻辑均在你的浏览器本地执行，数据不会上传到任何第三方服务器。
